# Projeto IA — Monitoramento de Estufa

Projeto acadêmico desenvolvido para aplicar conceitos introdutórios de Inteligência Artificial e apresentar, de forma didática, como eles podem ser usados em um cenário de monitoramento de estufa.

## Objetivo

Demonstrar conceitos de IA e processamento de dados por meio de exemplos simples. O projeto permite inserir temperaturas, observar tendências e classificações e explorar outras funcionalidades relacionadas a uma estufa didática.

## Conceitos e recursos aplicados

- Regressão linear para observar tendências e estimar valores.
- Perceptron para classificar leituras de temperatura.
- Cálculo de estatísticas das leituras, como média, variância e desvio padrão.
- Simulação de alerta para temperatura elevada.
- Fila de processamento e histórico de ações.
- Exemplos didáticos de probabilidade, redes neurais e suas aplicações.
- Processamento de imagem.
- Chatbot para interação com o usuário.

- Observação
Este projeto tem finalidade acadêmica e didática. As temperaturas são simuladas ou inseridas manualmente; o sistema não está conectado a sensores reais nem controla equipamentos de uma estufa.

## Organização

- `Parte1/`: primeira etapa do projeto, com exemplos de regressão linear e perceptron.
- `Parte2/`: sistema didático de monitoramento de estufa e funcionalidades complementares.
